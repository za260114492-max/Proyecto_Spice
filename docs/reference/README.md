# Referencias oficiales del proyecto

Este directorio es la fuente consultable de requisitos y metodología del proyecto SPICE educativo.

## Fuentes de verdad

1. [Especificación de la Unidad I](./ESPECIFICACION_UNIDAD_1.md) — alcance académico, circuito objetivo, requerimientos funcionales, entregables y evaluación.
2. [Guía metodológica](./GUIA_METODOLOGICA.md) — arquitectura, convenciones, skills, tools, validación, pruebas y organización del trabajo.
3. [Código y configuración vigentes](../../README.md) — describen qué está implementado hoy; el código ejecutable es la autoridad para el comportamiento real.
4. [Skills del agente](../../.github/skills/README.md) — metodología por dominio. Los nombres de tools incluidos en un skill no garantizan que esas tools estén implementadas.
5. [Planes de desarrollo e integración](../plans/) — trabajo propuesto; no son especificación de capacidades ya disponibles.

Si existe una discrepancia:

- Para el **requisito académico**, prevalece la especificación de la Unidad I.
- Para la **metodología aprobada**, prevalece la guía metodológica.
- Para la **capacidad implementada**, prevalecen el código y las pruebas actuales.
- Los documentos originales se conservan en [`originals/`](./originals/) para verificar contexto y diseño visual. No deben editarse como fuente principal cuando se actualiza una versión Markdown.

La [metodología resumida](./Guia_Metodologica_Custom_Agent_SPICE_Educativo.md) es material auxiliar de consulta; no reemplaza la guía completa ni la especificación académica.
