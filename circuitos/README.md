# Netlists de circuitos

Guarda aquí los netlists que quieras analizar (`.cir`, `.sp` o `.net`). Cuando pidas resolver un circuito sin adjuntar ni indicar una ruta, se buscará en esta carpeta. Si hay varios netlists y no queda claro cuál usar, se te preguntará.

Los netlists originales se leen sin modificarlos. Los resultados generados por las herramientas se guardan en `artifacts/`.
